## 🚀 Step-by-Step Guide

Follow the steps below in order.

### 1. 🎤 Check Roblox Voice Chat requirements

Before starting, make sure your account and region meet Roblox's current Voice Chat requirements.

Use Roblox's official help and account settings to complete any required age or identity verification.

### 2. 🖥️ Open the required Roblox page

Open the Roblox page shown in the video tutorial.

### 3. 🖱️ Open Developer Tools

Right-click on the page.

Choose:

**Inspect**

Then open the:

**Network** tab.

### 4. 🔄 Refresh the page

Reload the page by pressing **Ctrl + R**.

Wait a few seconds for the Network requests to load.

### 5. 🔎 Find the relevant request

Look through the Network requests for the request referenced in the tutorial.

> 💡 The exact request can vary depending on the page, browser, and Roblox changes.

### 6. 📋 Copy request information

If the tutorial asks you to copy request information, right-click the relevant request and use:

**Copy → Copy as PowerShell**

Do not share the copied request publicly if it contains private or sensitive information.

### 7. 🌐 Open the tutorial website

Open:

**[RobloTools Voice Chat](https://roblotools.com/voice-chat-unlocker/unc)**

Follow the website's instructions without entering your Roblox password or other private credentials.

## ❓ Troubleshooting

<details>
<summary><strong>🔎 I can't find the Network tab</strong></summary>

Open Developer Tools by pressing **F12**.

Then select **Network**.

</details>

<details>
<summary><strong>🔄 I can't find the request</strong></summary>

Refresh the page and wait until the Network list is populated.

The request name and position can change as Roblox updates its website.

</details>

<details>
<summary><strong>📋 "Copy as PowerShell" is not available</strong></summary>

Make sure you are right-clicking an actual network request in the **Network** panel.

</details>

<details>
<summary><strong>🎤 Voice Chat is still unavailable</strong></summary>

Check Roblox's current Voice Chat requirements, age eligibility, regional availability, and account settings.

</details>
